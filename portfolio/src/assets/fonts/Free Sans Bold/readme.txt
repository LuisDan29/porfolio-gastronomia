How to use this @font-face kit

1. Upload the included webfont files and stylesheet.css to your website. Keep the paths and filenames together unless you also update the URLs in the stylesheet.

2. Declare the font by copying the generated CSS from stylesheet.css into your main CSS file, or import stylesheet.css separately.

3. Apply the declared font family to the required elements using the standard CSS font-family property.

4. Test the page in a browser, verify that the font files return successfully, and keep a permitted fallback font in the font-family stack.
